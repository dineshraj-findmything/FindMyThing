# FindMyThing – Locate Everyday Objects
Camera-based assistant that helps visually impaired users find everyday
objects (water bottle, bag, book, keys) using audio guidance.

## Novelty
Guided search mode with voice instructions like "move the camera slowly to the left".

## Planned Prototype
Recognize a few predefined objects in a controlled environment and
give audio feedback.

## Tech Stack
Python, OpenCV, YOLOv8n / MobileNet-SSD, text-to-speech
